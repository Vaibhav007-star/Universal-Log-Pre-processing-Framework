Core Capabilities
Defense-Grade Intelligence
For Every Log Format

Eliminates the manual normalization bottleneck for cybersecurity analysts — from raw heterogeneous streams to actionable OCSF v1.1 threat intelligence.

🔍
Auto-Format Detection
Instantly classifies incoming logs as JSON, CEF, LEEF, RFC 5424 Syslog, Cisco ASA, Auditd, LEEF, or unknown — with a calibrated format confidence score between 0.0 and 1.0.
⚡
Hot-Path Deterministic Parsing
Known formats execute pre-compiled, zero-overhead regex plugins in under 200 microseconds per log — fully air-gap safe with no external service dependency.
🧠
JIT AI Synthesis (Cold Path)
Drain3 template mining + heuristic synthesizer learns new unknown formats on first encounter. Compiled rules persist in SQLite and hot-load into the live registry.
🛡️
OCSF v1.1 Canonical Schema
Normalizes every log into a strict Pydantic schema with timestamp (ISO-8601 UTC), endpoints, network metadata, actor, process, and verbatim raw log preservation.
🎯
MITRE ATT&CK Enrichment
Automatically correlates network actions and syscall patterns against the MITRE ATT&CK framework, tagging logs with technique IDs, tactic categories, and risk scores.
👥
Human-In-The-Loop Triage
Low-confidence logs (below configurable threshold) enter a review queue. Analyst corrections are compiled into permanent regex rules and immediately hot-loaded into runtime.
📊
Embedded DuckDB Analytics
Sub-millisecond columnar SQL analytics over millions of canonical events without external server overhead. Query threat data live via SQL studio in the dashboard.
🔒
Air-Gap & Privacy Preserving
AI inference is fully optional. Default heuristic mode requires zero internet connectivity, making it suitable for classified or offline defense networks.
📈
Multi-Level Confidence Scoring
Four distinct calibrated confidence metrics per log: format detection, field extraction validity, schema mapping completeness, and overall composite confidence.

⚡ HOT PATH — DETERMINISTIC COMPILED PARSER
Known log format → Pre-compiled regex plugin executes in <200 µs. Zero AI overhead, 100% offline-capable. Handles Cisco ASA, CEF, LEEF, RFC 5424, Auditd, JSON, and KeyValue formats natively.
🧠 COLD PATH — JIT AI SYNTHESIS ENGINE
Unknown format → Drain3 template mining extracts structure. Heuristic synthesizer (or optional Ollama/Gemini LLM) induces named-group regex. Rule is sandboxed, persisted to SQLite, and hot-loaded into the live registry.

REST API
Enterprise SIEM Integration

Full-featured FastAPI backend with interactive Swagger documentation. Wire directly into FluentBit, Rsyslog, Vector, Logstash, or any HTTP-capable log shipper.

POST
/api/v1/parse
Parse a single raw log line. Returns full canonical OCSF v1.1 record with all extracted fields and confidence scores.
POST
/api/v1/ingest
High-throughput batch ingestion of heterogeneous log arrays. Supports optional multiline trace assembly. Returns throughput EPS metrics.
GET
/api/v1/explain
Deep explainability view — returns every intermediate step of normalization including format classifier decision, selected parser, mapped fields, and error codes.
GET
/api/v1/stats
Aggregate analytics from DuckDB: total logs, average confidence, latency percentiles, format distribution, and action categorization breakdown.
GET
/api/v1/hitl/pending
Returns the current Human-In-The-Loop review queue — low-confidence events flagged for cybersecurity analyst verification and correction.
POST
/api/v1/hitl/approve
Commits analyst field corrections to permanent SQLite store and immediately hot-loads the new compiled rule into the active parser registry.
